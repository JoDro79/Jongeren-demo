# Jongeren 15–18 – demo

Demo van een registratie-app voor de jongerengroep van El Encuentro Con Dios, Purmerend: aanwezigheid met een persoonlijke QR-kaart, een dossier per jongere, een toestemmingsformulier en een dashboard.

**Alle namen en gegevens zijn fictief.** Wat je in de demo invult, blijft alleen in de browser van het apparaat waarop je het doet. Er gaat niets naar een server.

## Gebruik

- Open de link op een telefoon of laptop. Een account is niet nodig.
- **Scan kaart** opent de camera. Richt die op een QR-kaart (bij Jongeren → QR-kaarten tonen, op een ander scherm of geprint).
- **Demo opnieuw beginnen** (onderaan elke pagina) zet alles terug naar de beginstand.

Elk apparaat heeft zijn eigen demogegevens; wat op de ene telefoon wordt ingecheckt, verschijnt niet op de andere.
